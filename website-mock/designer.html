Tawala Designer

The legacy Tawala Designer is a desktop application for building forms, processes, and documents. Local browser work uses designer-web/ on port 5173; this mock site runs on :5500.

Open browser Designer → localhost:5173

Designer (:5173) and this mock (:5500) do not share storage. After opening Designer, use File → Open on the project JSON if it is not already loaded.

To deploy templates to local Java without the Designer Deploy button, use: 

node scripts/deploy-tawala-template.mjs "Template Name"

Browse templates in Library → · My Tawala project ops →
